I want to build a common space for idea dumping.

I want keyword search, semantic search over text and images (maybe audio and video too in the future, but not in current scope). I also want it to have an upload option which auto-tags the text notes and images, and gives you the option to edit the tags, notes, etc.

It should have a graph view of the connected notes and images. It should also provide me with a manual link creation option.

Example: I have a project X which has some assets. If I tag an asset A with "tree" and I search for tree, the search should return everything that matches the tag and also the things that semantically matches the tag.
